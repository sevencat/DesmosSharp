在 Desmos 中，输入表达式非常直观，它支持直接输入数学拼写（快捷命令）和使用内置的虚拟键盘。
以下是为你整理的 Desmos 表达式输入全攻略，按功能进行了分类：

1. 基础运算与特殊符号（快捷拼写）

你不需要满屏幕去找符号，直接在输入框用键盘打出以下英文字母，它们会自动变成数学符号：
• 平方与高次幂：输入 x^2 或 x 后按键盘的 Shift + 6 即可输入指数。
• 根号 (\(\sqrt{x}\))：直接输入 sqrt，它会自动变成根号。
• 立方根 (\(\sqrt[3]{x}\))：直接输入 cbrt。
• 圆周率 (π)：直接输入 pi，会自动变成 π。
• 分式/除法：输入分箱或括号后，直接打斜杠 / 即可变成上下结构的分式。
• 绝对值 (|x|)：直接输入 abs，或者按键盘上的竖线键 |（通常在 Enter 键上方）。

2. 核心数学功能输入指南


📊 函数与三角函数

• 标准函数：直接输入 y = sin(x)、f(x) = cos(x) 或 y = ln(x)。
• 对数函数 (\(\log _{a}b\))：
	• 常用对数直接打 log(x)。
	• 若要指定底数（如 \(\log _{2}x\)），先输入 log，然后按键盘的下划线 _（Shift + -）进入底数位置，输入 2，再按向右方向键 → 输入 x。

🎚️ 动态滑块 (Sliders)

• 包含未知常数的方程：当你输入带有未定义字母的方程时（例如 y = ax + b），Desmos 下方会出现提示按钮 全部 (all)。
• 点击它，a 和 b 就会变成可以左右拖动的滑块，图像会随着滑块的移动实时改变！

📐 不等式与区域阴影

• 大于/小于：直接输入 y > 2x 或 y < x^2。
• 大于等于/小于等于：先输入 > 或 <，紧接着输入一个等于号 =（即输入 >= 或 <=），Desmos 会自动将它们合并为 ≥ 或 ≤ 并渲染出实线和阴影区域。

🧩 分段函数与定义域限制

• 限制函数范围：在表达式后面加上花括号 {}。
	• 示例 1（限制定义域）：y = 2x {x > 0} （只画出 x 大于 0 的部分）。
	• 示例 2（标准分段函数）：y = {x < 0: -x, x >= 0: x}（用冒号连接条件和结果，用逗号隔开不同分段）。

📈 数据表格与回归拟合（数据分析）

1. 点击左上角的 + (添加项目) 按钮，选择 表格 (Table)。
2. 在表格中填入你的数据，上方表头默认会是 x₁ 和 y₁。
3. 进行数据拟合/回归：在下方新建一行，输入 y1 ~ m*x1 + b（注意：必须使用波浪号 ~，而不是等于号）。Desmos 会自动计算出斜率 m 和截距 b 并画出拟合直线。

⌨️ 强烈推荐：使用内置虚拟键盘

如果你忘记了某个快捷拼写，可以随时点击 Desmos 页面左下角的键盘图标 ⌨️：
• 左侧面板：包含平方、根号、不等式、π 等最常用的基础符号。
• 右侧 functions (函数) 按钮：点击它会弹出一个分类极其完整的菜单，涵盖了三角函数、统计学 (度数、方差)、微积分 (求和 \(\sum \)、积分 \(\int \)、导数 d/dx) 等所有高级命令，直接点击即可插入。
